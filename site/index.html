Cloud Security Project

AWS Security Monitoring

A cloud security monitoring environment built to collect, detect, and investigate security activity across AWS and Linux infrastructure.

AWS CloudWatch CloudTrail VPC Flow Logs Python EC2

Overview

I built this project to create centralized visibility into AWS control-plane activity, EC2 authentication events, and network traffic. CloudWatch collects the telemetry while metric filters and alarms detect specific security events. A Python analyzer provides an additional layer for investigating authentication and VPC Flow Log activity.

Architecture

CloudTrail + EC2 Logs + VPC Flow Logs → CloudWatch → Metrics & Alarms → Dashboard → Python Analysis

Security Dashboard

The CloudWatch dashboard provides a central view of authentication alerts, AWS control-plane events, rejected network traffic, source IPs, and targeted ports.

Detections

Failed SSH Authentication

Detects failed SSH password authentication events collected from the monitoring EC2 instance.

AWS Control Plane

Monitors CloudTrail activity for security-relevant IAM and infrastructure changes.

Network Rejections

Uses VPC Flow Logs to identify rejected traffic and frequently observed source addresses.

Targeted Ports

Tracks destination ports receiving rejected traffic to provide additional network context.

Security Analyzer

I wrote a Python analyzer to query authentication logs and VPC Flow Logs, summarize failed and successful SSH activity, identify rejected sources, and correlate authenticated hosts with network traffic.

End-to-End Validation

The monitoring pipeline was tested from event generation through detection and analysis to verify that each layer was receiving the expected telemetry.

Test Event → auth.log → CloudWatch Agent → CloudWatch Logs → Metric Filter → Alarm → Dashboard → Analyzer
